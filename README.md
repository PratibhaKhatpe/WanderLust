# 🏡 WanderLust

WanderLust is a full-stack Airbnb-inspired web application where users can explore, create, update, and review property listings. 
The project demonstrates real-world concepts such as authentication, authorization, MongoDB relationships, session management, and location-based services using interactive maps.

## ✨ Features

- User authentication (Signup/Login)
- Create, edit, and delete property listings
- Add and delete reviews
- User authorization and protected routes
- Interactive maps using Leaflet.js
- Image upload and storage
- Flash messages for better user experience

## 🛠️ Tech Stack
